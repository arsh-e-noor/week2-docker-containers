# Week 2 - Docker Containers & CI/CD Pipeline (Internship Submission)

## 📌 Overview
This week focused on mastering Docker fundamentals, multi-container applications using Docker Compose, and implementing CI/CD pipelines using Jenkins integrated with Docker.

The goal was to containerize applications, optimize images, manage multi-service architecture, and automate deployment pipelines.

---

## 🎯 Learning Objectives

- Understand Docker basics and container lifecycle
- Build and optimize Docker images
- Work with multi-container applications using Docker Compose
- Push Docker images to Docker Hub / AWS ECR
- Implement CI/CD pipelines using Jenkins
- Integrate GitHub with Jenkins for automation
